THE UNTOLD STORIES OF FULƁE — WEBSITE STARTER

FILES
- index.html: complete responsive website. No build tools are required.
- README.txt: these instructions.

PREVIEW LOCALLY
1. Extract the ZIP.
2. Open index.html in a browser. An internet connection is needed for the remote photography.
3. Replace the placeholder editorial email stories@example.com in index.html with your real email address.

FREE HOSTING OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository, e.g. untold-stories-fulbe.
3. Upload index.html (and this README if you wish) to the repository root.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, select “Deploy from a branch”, choose the main branch and /(root), then Save.
6. Wait for the deployment and use the website URL shown on the Pages settings screen. It usually looks like https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
GitHub's interface can change; see https://docs.github.com/pages for current instructions.

IMPORTANT LIMITATIONS
- Hosting can be free. A custom domain such as yourname.com normally costs extra.
- This is a front-end starter site. The search, category filter, mobile menu, and sample-story dialogs work in the browser.
- The submission form opens a prepared email draft; it does not securely collect or store submissions. Replace stories@example.com with your editorial email, or connect a form service/backend before inviting the public to submit.
- Newsletter signup is a demo only and does not store email addresses. Connect a mailing-list provider if you want real subscriptions.
- Photography is loaded from Unsplash URLs, so an internet connection is needed for the images. Replace images with photographs you have permission to publish.
- Story cards are clearly intended as sample copy. Verify historical claims with reliable sources, identify uncertainty, seek informed consent for oral histories, and respect privacy and cultural sensitivities before publication.
- The site's language is English as requested.
